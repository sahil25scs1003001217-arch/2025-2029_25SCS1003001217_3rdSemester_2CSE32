## 🎯 Objectives

- Learn how webpages are structured using HTML
- Learn how to style webpages and make them look neat using CSS
- Learn the basics of making a webpage responsive (works on mobile and desktop)
- Learn simple JavaScript to make a webpage interactive
- Practice using Git and GitHub to save and share code
- Build small, easy practice tasks after every topic
- Put everything together into one simple final project
- Publish the final project online so it can be shared with a link

---

## 🗓️ Week-wise Curriculum (Easy, Beginner-Friendly)

| Week | Module | Description |
|---|---|---|
| 1 | HTML Basics | Learn the building blocks of a webpage — headings, paragraphs, images, links, and lists. Practice task: make a simple "About Me" page. |
| 2 | CSS Basics | Learn how to add colors, fonts, spacing, and layout to a webpage using CSS. Practice task: style the "About Me" page. |
| 3 | Making Pages Responsive | Learn simple techniques (Flexbox and media queries) to make a page look good on both mobile and desktop. |
| 4 | Introduction to JavaScript | Learn JavaScript basics — variables, simple functions, and how to respond to a button click. |
| 5 | Interactive Webpages | Use JavaScript to change text, show/hide content, and build a simple interactive feature like a to-do list. |
| 6 | Working with Forms | Learn how to build a simple contact form and validate basic input (like checking if a field is empty). |
| 7 | Git, GitHub & Hosting | Learn how to save code with Git, push it to GitHub, and publish a website for free using GitHub Pages. |
| 8 | Final Project Week | Combine everything learned into one simple final project (see below), test it, and publish it online. |

> **Note:** Every week is kept simple on purpose — the goal is to understand the basics clearly before moving to more advanced topics later.

## 💡 Easy Final Project: Personal Portfolio Website

A simple, beginner-friendly project that uses only what was learned during the internship — no backend or database needed.

**What it is:** A one-page personal portfolio website with:
- A home section with your name and a short intro
- An "About Me" section
- A "Skills" section (simple list or icons)
- A "Projects" section (2–3 sample cards)
- A "Contact" section with a simple form
- A responsive layout that works on mobile and desktop
- A little bit of JavaScript, for example a working "dark mode" toggle button

**Why this project:** It only needs HTML, CSS, and a small amount of JavaScript — the exact things covered week by week — so it's realistic to finish as a beginner, and it's genuinely useful afterward (you can share the live link on your resume/LinkedIn).

**Tools used:** HTML5, CSS3, JavaScript (basics), Git & GitHub, GitHub Pages (for free hosting)
